# SE 250 Lab: Costume Closet
Dishant Lama
A small CRUD web app (HTML, PHP, MySQL) for tracking costume loans after Halloween.

## Setup
1. Start Apache and MySQL (XAMPP or MAMP).
2. Import `costume_closet.sql` in phpMyAdmin.
3. Check the password in `db.php` matches your setup.
4. Open `localhost/<repo-folder>/list.php`.

## Files
- `db.php` database connection
- `add.php` form to add a loan (Create)
- `list.php` table of loans, search, and "still out" filter (Read)
- `mark_returned.php` marks a loan returned (Update)
- `delete.php` deletes a loan (Delete)

## Stretch goals done
